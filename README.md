# 3rd Year BSIT Student Portfolio

A modern, responsive, and fully self-contained personal developer portfolio built for a 3rd-year Bachelor of Science in Information Technology (BSIT) student. Designed to be lightweight and ready to push straight to GitHub Pages with zero complex setup or external folders required.

 Features

* **Single-File Architecture:** All HTML, CSS, JavaScript, and live applications are self-contained within `index.html` for instant deployment and viewing.
* **Aesthetic Dark Mode UI:** Built with a sleek glassmorphism design, smooth section scrolling, and a polished purple/indigo color palette.
* **Interactive Navigation:** Fully working nav links (Home, About, Skills, Projects, Education, Contact) and mobile-responsive menu.
* **Profile Photo Support:** Includes a built-in avatar placeholder and a local photo previewer (supports dropping or linking `profile.jpg`).
* **Embedded Live Systems (Projects):** Features three fully functional web applications built directly inside the portfolio so visitors can test them live without downloading separate projects:
  1. **Digital Queue & Appointment System:** Manages administrative window queues and student appointments.
  2. **IT Lab Equipment Inventory & Borrowing Tracker:** Tracks hardware assets, serial numbers, and borrow statuses with item management.
  3. **Micro-Business POS & Order Tracker:** Calculates totals, handles product selections, and logs sales transactions.

---

 Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Glassmorphism styling), JavaScript (ES6+)
* **Icons & Fonts:** FontAwesome / Google Fonts (Inter)
* **Hosting / Deployment:** GitHub Pages
